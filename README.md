# Float98 — Portfólio

Portfólio pessoal no estilo **Windows 98**, feito com HTML, CSS e JavaScript puro + [98.css](https://jdan.github.io/98.css/).

![banner](./img/char.png)

## ✨ Destaques

- Interface temática Windows 98 (janelas, title bars, status bar, botões e painéis)
- Busca automática dos projetos em tempo real via **GitHub API** (`floatingskies`)
- Cada projeto mostra: descrição, linguagem, ⭐ stars, forks, issues, licença, datas, topics e links
- Troca de idioma PT/EN
- Totalmente responsivo

## 🛠️ Como rodar

Basta abrir o `index.html` no navegador, ou servir localmente:

```bash
python3 -m http.server 8000
```

Acesse `http://localhost:8000`.
